# Hearing and Visual Accessibility

Use this skill when a guest is deaf, hard of hearing, blind or has low vision and needs adapted service.

1. Call `check_accessibility_options` with need hearing or visual to see hearing loops, braille menus and guide dog policy.
2. For hearing, pick quiet venues using `get_venue_ambience` below 65 dB and a table away from the kitchen.
3. Offer written communication by `send_sms` or email instead of phone calls.
4. For visual needs, ask the venue for a large-print or braille menu via `get_restaurant_menu` and a staff member to read the menu.
5. Service animals are always welcome; note it in the booking.
6. Add a note for the host about preferred guidance.

Never: assume the guest wants help; ask first.
