# Refund Playbook

Use this skill when the user asks about cancellation, refund, or credit eligibility.

1. Retrieve the booking or order status.
2. Retrieve the applicable policy note.
3. Compare the policy against the user's reason and timing.
4. If the policy is ambiguous or exception-based, escalate to a human.
5. If the answer is clear, explain the decision and cite the policy memory used.
